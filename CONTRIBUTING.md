# Contributing

This repository is maintained as a read-only technical case study. External contributions are not accepted.

Please do not:

- open feature requests or general-purpose issues;
- submit external pull requests, patches, or documentation changes; or
- use repository discussions or comments to propose product work.

Security concerns must follow [SECURITY.md](SECURITY.md). Do not place secrets, credentials, personal data, customer information, financial or operational data, sensitive screenshots, production-system concerns, or vulnerability details in a public issue, pull request, discussion, or comment.

If this repository is made public through GitHub, the ability to view or fork it through GitHub does not constitute an invitation to contribute, an additional general license, or authorization for other uses. The intentional no-general-license position is documented in [docs/licensing.md](docs/licensing.md).

The contribution policy may change only through an explicit future decision documented by the repository maintainers. Until then, external contributions, feature requests, public issue reports, and pull requests remain outside the accepted participation model.
