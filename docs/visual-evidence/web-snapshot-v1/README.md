# LEM-BOX Web Platform — Web Snapshot v1

This directory contains nine PNG captures of the real LEM-BOX web interface as captured in August 2026. The selected views cover administrative and operations work, operator intake, customer self-service, partner-scoped work, and web operational reporting.

All record-level identities, identifiers, dates, quantities, regions, states, weights, and other business values shown are purpose-built synthetic data. No production data was anonymized, transformed, sampled, exported, or blurred into these images.

The images are not LinkedIn screenshots, were not generated or reconstructed with AI, and do not claim that the interface is final or permanently current. Mobile, Telegram, messaging, bot, and internal-assistant surfaces are intentionally excluded.

[`manifest.json`](manifest.json) records only safe public metadata: the snapshot identity, capture month, public image titles, dimensions, SHA-256 values, limitations, and refresh policy. Private source, build, environment, URL, account, and capture-process details are intentionally excluded.
