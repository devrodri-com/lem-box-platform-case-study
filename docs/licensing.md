# Licensing

## Intentional rights position

This repository does not include a `LICENSE` file and grants no general license. All rights remain reserved by default.

If this repository is made publicly available through GitHub, users may view and fork it through GitHub as permitted by [GitHub's Terms of Service](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service#5-license-grant-to-other-users). Those platform permissions do not grant broader rights to use the content outside the Service or for other purposes.

Except for rights provided by applicable law and GitHub's Terms of Service, additional use requires permission from the applicable rights holder.

This repository must not be described as open source.

## Material covered by this position

Unless a future file states otherwise expressly and with an exact scope, the no-general-license position applies to all repository content, including:

- documentation and diagrams;
- screenshots and other images;
- names, visual identity, and branding material;
- synthetic fixtures and manifests; and
- independently reimplemented technical examples and tests.

No legal or corporate rights holder beyond what is confirmed in the repository is asserted here.

## Future licensing decisions

A future decision may grant specific permissions for a precisely identified file or content class. Any such permission must be stated explicitly, name its exact scope, and include the applicable terms.

A future license for selected examples would apply only to the files it identifies. It would not automatically extend to documentation, images, branding, fixtures, other examples, or the repository as a whole.

Unless an express scoped grant is added, no additional permission beyond rights provided by applicable law and GitHub's Terms of Service should be inferred.

## Contributions

External contributions are not accepted under the current repository policy. See [Contributing](../CONTRIBUTING.md). This avoids implying any inbound or outbound license beyond the rights position documented above.
